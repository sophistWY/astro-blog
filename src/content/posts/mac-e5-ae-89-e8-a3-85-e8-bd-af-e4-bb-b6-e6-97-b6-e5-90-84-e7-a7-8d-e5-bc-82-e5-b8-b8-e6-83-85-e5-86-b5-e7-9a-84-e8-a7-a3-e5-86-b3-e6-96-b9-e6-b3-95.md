<h3 id="提示程序含有恶意代码或者已经打开所有来源还是提示扔到垃圾桶"><a href="#提示程序含有恶意代码或者已经打开所有来源还是提示扔到垃圾桶" class="headerlink" title="提示程序含有恶意代码或者已经打开所有来源还是提示扔到垃圾桶"></a>提示程序含有恶意代码或者已经打开所有来源还是提示扔到垃圾桶</h3><p>基本上在11以后的系统上必备命令行，具体报错图如下</p>
<p><a href="https://s4.ax1x.com/2022/01/24/7IbGt0.png" target="_blank" rel="noopener"><img src="/legacy-assets/e6ad109028-1.png" alt="Mac安装软件时各种异常情况的解决方法"></a></p>
<p>解决方法：在终端输入 xattr -r -d com.apple.quarantine 加上程序的App绝对路径，App建议直接拖放到终端，会自动填写路径，比如QQ，最终应该是这样的一个终端命令</p>
<blockquote>
<p>xattr -r -d com.apple.quarantine /Applications/QQ.app<strong>（/Applications/QQ.app 前面有一个空格）</strong></p>
</blockquote>
<h3 id="Mac安装软件时提示“the-installation-cannot-continue-as”"><a href="#Mac安装软件时提示“the-installation-cannot-continue-as”" class="headerlink" title="Mac安装软件时提示“the installation cannot continue as”"></a>Mac安装软件时提示“the installation cannot continue as”</h3><p>这种错误常见于10.15以后的系统中安装Adobe系列软件时候出现，报错如下图</p>
<p><img src="/legacy-assets/3d6dceb7d7-2.webp" alt="Mac安装软件时提示“the installation cannot continue as”"></p>
<p>解决方法如下：</p>
<ol>
<li>双击打开dmg安装包</li>
<li>在 install.app 上右键，选择 显示包内容</li>
<li>依次进入 Contents 下的 MacOS 目录</li>
<li>双击 MacOS 目录中的 install 即可开始正常的安装流程了</li>
</ol>

<p>把没有权限的CORE Keygen拷贝到桌面，右键显示包内容，进入Macos目录，里面有一个文件</p>

<h3 id="安装出现闪退等其他情况"><a href="#安装出现闪退等其他情况" class="headerlink" title="安装出现闪退等其他情况"></a>安装出现闪退等其他情况</h3><p>2019年7月10号开始，很多TNT破解软件大面积报错，原因不多说，讲一下具体的解决方案</p>
<h4 id="步骤一："><a href="#步骤一：" class="headerlink" title="步骤一："></a>步骤一：</h4><p>安装xcode，这个在商店里面有，不想安装的，按步骤二来。</p>
<h4 id="步骤二："><a href="#步骤二：" class="headerlink" title="步骤二："></a>步骤二：</h4><p>安装Command Line Tool 工具</p>
<p>打开终端输入以下命令</p>
<blockquote>
<p>xcode-select –install <strong>（install前面为两个短横线）</strong></p>
</blockquote>
<h4 id="步骤三："><a href="#步骤三：" class="headerlink" title="步骤三："></a>步骤三：</h4><p>终端继续输入以下命令</p>
<blockquote>
<p>codesign –force –deep –sign - <strong>（force、deep、sign前面为两个短横线）</strong></p>
</blockquote>
<p>然后拖入需要签名的软件，最后类似于这样</p>
<blockquote>
<p>codesign –force –deep –sign - /Applications/name.app <strong>（/Applications前面有一个空格）</strong></p>
</blockquote>
<p>回车搞定</p>

<h3 id="Parallels-Desktop-16-0-0-无法安装"><a href="#Parallels-Desktop-16-0-0-无法安装" class="headerlink" title="Parallels Desktop 16.0.0 无法安装"></a>Parallels Desktop 16.0.0 无法安装</h3><p>报错的本质是10.15以上的系统，安装程序本身不能执行，解决思路就是xattr处理，由于安装包本身为隐藏文件，所以不能简单拷贝后处理，列出命令行步骤，大家照着处理下</p>
<p>1、取消隐藏文件</p>
<blockquote>
<p>defaults write com.apple.finder AppleShowAllFiles Yes &amp;&amp; killall Finder</p>
</blockquote>
<p>2、把隐藏的 Parallels Desktop 拖到 Applications（应用程序）</p>
<p>3、分别执行 xattr和codesign 两个10.15系统必备操作命令</p>
<blockquote>
<p>chflags nohidden /Applications/Parallels\ Desktop.app</p>
<p>xattr -cr /Applications/Parallels\ Desktop.app</p>
<p>codesign –sign - –force –deep /Applications/Parallels\ Desktop.app</p>
</blockquote>
<p>4、双击即可正常使用</p>
<p>5、关闭隐藏文件</p>
<blockquote>
<p>defaults write com.apple.finder AppleShowAllFiles No &amp;&amp; killall Finder</p>
</blockquote>
