<h2 id="Flutter-实战"><a href="#Flutter-实战" class="headerlink" title="Flutter 实战"></a>Flutter 实战</h2>
<h4 id="一-前置概念"><a href="#一-前置概念" class="headerlink" title="一.前置概念"></a>一.前置概念</h4><p><strong>1. Flutter module</strong> </p>
<p><strong>概念：</strong></p>
<p>将Flutter添加到你的既有 iOS 应用中(利用CocoaPods)</p>
<p><strong>创建 :</strong></p>
<figure class="highlight shell"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br></pre></td><td class="code"><pre><span class="line">cd some/path/</span><br><span class="line">flutter create --template module my_flutter</span><br></pre></td></tr></table></figure>
<p><strong>2. 原生插件</strong> <strong>(Plugin packages)</strong></p>
<p><strong>概念：</strong></p>
<p>使用 Dart 编写的，按需使用 Java 或 Kotlin、Objective-C 或 Swift 分别在 Android 和/或 iOS 平台实现的 package。</p>
<p><strong>创建 :</strong></p>
<figure class="highlight shell"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br></pre></td><td class="code"><pre><span class="line">// 使用 -a 选项指定 Android 的语言，或使用 -i 选项指定 iOS 的语言</span><br><span class="line">flutter create --org com.example --template=plugin --platforms=android,ios -a kotlin -i swift flutter_plugins</span><br></pre></td></tr></table></figure>
<p><strong>3. 纯</strong> <strong>Dart</strong> <strong>库</strong> <strong>(Dart packages)</strong> </p>
<p><strong>概念：</strong></p>
<p>用 Dart 编写的传统 package，比如 <a href="https://pub.flutter-io.cn/packages/path" target="_blank" rel="noopener">path</a>。其中一些可能包含 Flutter 的特定功能，因此依赖于 Flutter 框架，其使用范围仅限于 Flutter，比如 <a href="https://pub.flutter-io.cn/packages/fluro" target="_blank" rel="noopener">fluro</a>。</p>
<p><strong>创建：</strong></p>
<figure class="highlight shell"><table><tr><td class="gutter"><pre><span class="line">1</span><br></pre></td><td class="code"><pre><span class="line">flutter create --template=package flutter_packages</span><br></pre></td></tr></table></figure>
<p><strong><em> Tips：</em></strong></p>
<ol>
<li><p>你的应用将不能在模拟器上运行 Release 模式，因为 Flutter 还不支持将 Dart 代码编译成 x86/x86_64 ahead-of-time (AOT) 模式的二进制文件。</p>
</li>
<li><p><code>Flutter.framework</code> 是 Flutter engine 的框架， <code>App.framework</code> 是你的 Dart 代码的编译产物。</p>
</li>
<li><p><a href="https://flutter.cn/docs/development/packages-and-plugins/developing-packages" target="_blank" rel="noopener">参考文档 &gt;&gt;</a></p>
</li>
</ol>
